# Project UI/UX Guidelines & /unslop Slash Command

Whenever the user issues `/unslop` or requests to unslop, polish, or clean up AI design in this project:

1. **Activate the `unslop` Skill**: Read and follow `.agents/skills/unslop/SKILL.md` (or global `unslop`).
2. **Execute the 9 Ordered Passes**:
   - **Spacing**: Strict 4px grid; uniform row heights; space indicates hierarchy.
   - **Color**: Unified neutral ramp + 1 deliberate accent; strip neon glows, multi-hue gradients, and blurred background color blobs.
   - **Icons**: Consistent line icons (Lucide); eliminate emojis as UI labels.
   - **Copy**: Crisp, honest product copy; no exclamation marks; no AI hype buzzwords.
   - **Type**: 400-600 weights, sentence case, tabular numerals for metrics.
   - **Layout**: Full desktop app proportions (wide layout, proper optical center).
   - **Details**: Nested radii (`R_inner = R_outer - padding`), quiet hairlines.
   - **Visuals**: Real product moments rather than generic decorative filler.
   - **Motion**: Functional feedback easing; eliminate arbitrary continuous pulsing or bouncing.
